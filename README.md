# Over view of the rules of Pac-Man:
- The main goal in Pac-Man is to eat all of the pellets in the maze while avoiding the ghosts.
  After succesfully eating all of the pellets, the player will advance to the next level.
- To move Pac-Man you can use the arrow keys.
- Pellets are worth 10 points, energizers turn the ghosts blue for a few seconds so you can eat them,
  and fruits appear around the map and are worth bonus points.
- You can push the "esc" button at anytime to exit the game and input your initials which will save your score.

# How to run our program: 
- Run my_flask.py. From there you can click the "play" button which will allow you to play the game.

# Over view of what is in "final-spring-start-point":
- test.py contains the bulk of the program.
- tile.py creates the map which the game is played on.
- my_flask.py holds the python flask and is designed in index.html which is stored in the templates folder.
- pacman_store.db holds the database where the player score are kept.
